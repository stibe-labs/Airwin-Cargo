# Airwin Cargo - Official Website

Modern, high-performance responsive web experience for **Airwin Cargo & Logistics**, featuring seamless GSAP-powered interactive scroll animations, road curves, logistics fleet telemetry, and comprehensive global service showcases.

## Features
- **Cinematic Scroll Journey**: Smooth GSAP + ScrollTrigger animations guiding visitors through freight operations, reach stacker crane loading, road logistics, and aviation cargo transitions.
- **Responsive Navigation**: Full desktop and mobile support with smooth scrolling (Lenis).
- **Service Portfolios**: Dedicated pages for Air Freight, Ocean Freight, Customs Brokerage, Warehousing, and Land Transport.
- **Global Network & Tracking**: Integrated telemetry speedometer and milestone showcases.

## Project Structure
- `index.html` - Homepage featuring the interactive scrolling freight narrative
- `about.html` / `about/` - Company background, mission, and fleet strengths
- `services.html` / `services/` - End-to-end global supply chain services
- `industries.html` / `industries/` - Industry solutions (Pharma, Automotive, Retail, etc.)
- `insights.html` / `insights/` - Market intelligence and logistics articles
- `contact.html` / `contact/` - Global headquarters and office contact directory
- `css/` - Optimized stylesheets and typography
- `js/` - Interactive animation modules, GSAP chunks, and Three.js scenes

## Local Development
Run the local static server:
```bash
node server.js
```
Or open `index.html` directly in any modern web browser.
